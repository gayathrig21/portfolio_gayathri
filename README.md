# Your project portfolio

A small website built with HTML, CSS, and JavaScript. It needs no installation or build command. All project descriptions and personal details are starter content for you to replace.

## Open it

Open `index.html` in your browser. After editing a file, save it and refresh the browser to see your changes.

## Understand the three files

- `index.html` defines the content and its meaning: navigation, sections, headings, and project cards.
- `styles.css` controls the colors, spacing, card illustrations, and responsive layout. The variables at the top are the easiest place to experiment.
- `script.js` makes the category buttons filter project cards and updates the footer year. Read it alongside the HTML attributes `data-filter` and `data-category`.

## Your first exercise

1. Replace `Your Name` in the page title, navigation, introduction, and footer.
2. Rewrite the introduction in two sentences: what you build and what interests you.
3. Replace the first example card with a real project. Describe the problem and your contribution. Keep the example label until the content is accurate.
4. Inside its `details` element, add a repository link using `<a href="YOUR_REAL_REPOSITORY_URL">View source code</a>`. Add a demo link only if you have a working demo.
5. Change `--accent` at the top of `styles.css` and observe what changes.
6. Resize the browser. Check the navigation and cards on a narrow screen, and use Tab to navigate the page.

To add another project, copy an entire `article` element inside `.project-grid`. Set `data-category` to `ai` or `web`, matching a filter button. You can also add a category by adding a button with a corresponding `data-filter` value.

## Before publishing

Replace the example email, About text, metadata description, and all sample project content. Replace the decorative card artwork with actual screenshots when available, using descriptive image alt text. Try every link and project filter.

For eventual deployment, copy the contents of this folder to a dedicated portfolio repository so its `index.html` is at that repository's root. This keeps publishing settings independent of your course repository. No publishing configuration has been added here.
